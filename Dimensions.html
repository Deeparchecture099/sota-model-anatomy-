hy the Context Window Fails as Working Memory

  1. It is Static Read-Only Data

In a human brain, working memory allows you to take many facts, smash them together, discard the irrelevant details, and form a new compressed thought.

An LLM cannot change the past tokens inside its context window. Every word already generated is locked in stone. The model can only append new tokens to the end of the string. It cannot dynamically edit its active thoughts.

  1. Attention is Not Manipulation

The Attention mechanism ((QK^{V})) inside a transformer is essentially a massive, sophisticated search engine over the context window.

When the LLM generates a new word, it looks back at the context window to see which past words are most relevant. This is retrieval, not manipulation. It is the equivalent of a human having a textbook open on their desk and glancing back at page 2—it is externalized storage, not active mental processing.

  1. No Internal Scratchpad

When a human solves a complex math problem, their working memory holds intermediate variables, tracks hypotheses, and suppresses distractions.

Because an LLM transfers information directly from the static context window to the next token output, it has no hidden, internal “scratchpad” to test out ideas before committing them to print. If it thinks a bad thought, that thought is instantly written into the context, polluting all future reasoning.

Neuromodulation: The Engine of Meta-Reasoning & Awareness

📌 Core Concept

Neuromodulation is the process by which specific chemical messengers (neuromodulators) alter the cellular or synaptic properties of entire neural circuits in real time. Unlike standard neurotransmitters (like glutamate or GABA), which pass specific data from point A to point B, neuromodulators act as a systemic fluid overlay. They do not carry the data itself; they rewrite the operating rules of the data-processing network while it is running.

Contextual Tuning: It shifts the system’s baseline risk tolerance, search focus, and error margins based on how well the current problem-solving strategy is going. Dynamic Resource Allocation: It decides which circuits are granted maximum energy/attention and which are suppressed to avoid dead ends.
